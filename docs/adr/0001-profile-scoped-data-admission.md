# Use profile-scoped, verifier-issued data admission

Auto-alpha distinguishes immutable Source Freeze Generations from Canonical Data Freezes and grants the canonical name only to a profile/view/span scope admitted by an independent verifier. A content-addressed Data Admission Profile selects base, conditional, and inactive dataset/field closures; this replaces the global 41-dataset declaration, the 15-dataset hard-gate split, and producer-issued readiness flags because those alternatives either block unrelated research inputs or permit self-attested evidence.

## Consequences

- Research Contracts bind one human-activated profile and cannot relax it during a campaign.
- Coverage is proved from provider-neutral obligations and terminal receipts rather than aggregate completeness claims.
- Changes outside the active Data Scope Root do not trigger a Research Campaign.
- Blocked Source Freeze Generations remain auditable but carry no research authorization.
- The current real lake remains blocked until its event coverage, PIT membership, derived validity/target lineage, and deterministic replay evidence satisfy the contract.
